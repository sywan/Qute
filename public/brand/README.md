# Qute logo

The on-screen logo in the header is drawn with CSS (`.brand-mark` in `src/styles.css`: a 39 px
rounded square, colour `#a48ad5`, white Georgia "Q", rotated −8°). These files are the same mark
as images, for favicons, slides, documents and social posts.

| File | Use |
| --- | --- |
| `qute-logo.svg` | Vector master (the "Q" is outlined, so no font is needed) |
| `qute-logo-1024.png`, `qute-logo-512.png` | Documents, slides, social media (transparent background) |
| `qute-logo-192.png` | Android / web-app icon |
| `qute-logo-180.png` | Apple touch icon |
| `qute-logo-32.png`, `favicon.ico` (16/32/48) | Browser tab icon |

Colours: purple `#a48ad5`, white `#ffffff`, page background `#f9f5ee`, text `#29272a`.
The "Q" outline comes from Gelasio Bold (metric-compatible with Georgia; SIL Open Font License 1.1).
