# Qute v0.2.1 功能增補

本版延續 [v0.2 產品規格](PRODUCT_SPEC_v0.2.md)，聚焦自選參考圖與現場拍照。

## 使用流程

1. 訪客在桌機或手機開啟 GitHub Pages 網站，免登入。
2. 可上傳或拖放原始照片，也可按「開啟相機」；瀏覽器此時請求相機權限，顯示即時預覽，按「拍攝照片」取景。已有照片時仍可按「重新拍照」。
3. 選「自選參考圖」時，可拖放參考圖片或從檔案選擇器挑選。介面顯示縮圖與檔名。
4. 可調整風格強度；自選參考圖可選「加強插畫感」，讓模型做第二次風格遷移。完成後下載 PNG 或使用裝置分享功能。

## 相機與隱私

- 只有使用者按相機按鈕才呼叫 `getUserMedia`。請求僅含影像，不含麥克風。
- 權限被拒、找不到相機、瀏覽器不支援時顯示對應訊息。拍照、取消、離開頁面時停止攝影機串流。
- GitHub Pages 使用 HTTPS，可滿足瀏覽器安全環境要求；瀏覽器或系統仍須允許相機權限。
- 原始照片、參考圖、成品只在目前瀏覽器工作階段處理，不上傳至 Qute 伺服器。

## 畫風品質界線

- 現用 Magenta.js 模型是任意風格遷移，主要改變色彩與紋理。二次轉換可增強插畫感，但可能損失人臉細節，處理時間也較長。
- 上傳 Q 版插畫**不能**讓此模型可靠地把真人重繪成大頭身 Q 版；團體照的人數、姿勢與身份一致性沒有保證。
- 若下一版要達成真正 Q 版重繪，需另設計生成式影像工作流，評估模型、裝置效能、照片傳送與成本，再決定如何維持免登入與 GitHub Pages 的公開入口。
