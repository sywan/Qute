# Qute v0.3.14 整合紀錄

## 版本關係

v0.3.13 的 Git 歷史已包含 v0.2.2 (`86f7918`)，因此不需要重新合併或覆蓋舊版程式。v0.3.14 以 v0.3.13 為基礎，整理原始需求、現有實作和兩種處理模式的說明。

| 原始需求與 v0.2.2 功能 | v0.3.14 狀態 |
| --- | --- |
| React、繁體中文／英文切換、免登入、GitHub Pages | 保留 |
| 照片上傳、拖放、相機拍攝、左右翻轉、亮度／對比／飽和度 | 保留 |
| 自選參考圖拖放、預覽、色彩與筆觸調整 | 保留；v0.3 分離配色與筆觸，預設避免大面積塗抹 |
| Q 版團體照 | 瀏覽器版以臉部偵測、幾何變形和 AnimeGAN 實作；生成式二頭身需自行架設 InstantID 伺服器，仍可能誤畫人物與細節 |
| 下載與分享 | PNG；大於 4.2 MP 時使用 JPEG；支援裝置分享 API |
| QR 碼 | 現有 QR 僅開啟 Qute 網站；**尚無每張成品的跨裝置下載 QR** |

## 隱私邊界

- **瀏覽器演算法**：照片與參考圖留在目前瀏覽器處理。初次使用會下載模型；不須登入。
- **自選伺服器演算法**：照片及所選參考圖傳送到訪客填入的伺服器網址。Qute GitHub Pages 不提供或代管該伺服器。訪客應確認該網址由自己或信任的管理者控制。
- v0.3.14 將首頁、狀態列、「為什麼用 Qute？」與 README 的絕對「不上傳」敘述改成依模式說明。參考圖提示也改為區分「配色／筆觸」與「Q 版比例變形」。

## 驗證

- 以 v0.3.13 的乾淨 Git 提交建立隔離副本後，`npm test`：26 項通過；`npm run build`：成功。
- `server` 的 `pytest`：11 項通過。測試包含本機 socket 與 ONNX CoreML 暫存檔，需在允許這兩種資源的環境中執行。
- 模型品質、實體相機、所有瀏覽器與自架 GPU 模型仍需以真實裝置與部署環境驗收；單元測試不能證明團體照的 Q 版品質。
