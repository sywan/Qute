# Qute 產品規格 v0.2

日期：2026-11-08。繼承 [v0.1 規格](PRODUCT_SPEC.md)，並依使用者最新要求更新。

## 產品決策

1. 前端改為 React + Vite；`sywan/Qute` 的 `main` 分支觸發 GitHub Actions 建置，將 `dist/` 發布到 GitHub Pages。
2. UI 語言只有繁體中文（`zh-TW`）與英文（`en`）；預設繁體中文。切換後即時更新介面文字，重新開啟時保留所選語言。
3. 照片風格轉換改用 Magenta.js 的神經風格遷移模型，訪客按下轉換時才下載模型。原本 v0.1 的像素濾鏡不再是主要體驗。
4. 風格選項對應具體公有領域畫作：梵谷《臥室》、莫奈《睡蓮》、達文西《蒙娜麗莎》。另提供自選參考圖。
5. 照片只在瀏覽器內處理；仍無登入、圖片後端或跨裝置結果 QR 下載。

## 使用流程

選照片或拍照 → 選參考畫作或上傳自選參考圖 → 調整風格強度 → 按「用 AI 轉換照片」 → 查看原圖與結果 → 下載或系統分享。

## 能力邊界

神經風格遷移能將參考畫作的色彩與筆觸套用到照片，比單純線條濾鏡更具畫作質感；它保留大致構圖，**不是**文字提示驅動的圖生圖生成，不會可靠地把七人合照變成附圖那種大頭身 Q 版。真正的 Q 版人物重繪仍需另選生成式模型或後端，並檢查人數、身份與站位。

宮崎駿等在世創作者的作品不作為內建參考圖片。使用者可用自己有權使用的圖片試驗自選風格；App 不宣稱創作者參與或授權。

模型首次使用需要下載權重，且效果、耗時和可用性受瀏覽器、GPU、記憶體及網路影響。輸出長邊上限 640 像素，以減少手機記憶體壓力。單張輸入圖上限 20 MB。

## 驗收

- GitHub Pages 子路徑 `/Qute/` 可載入 React JS、CSS、三幅參考縮圖。
- 預設繁體中文，點選 EN 後介面與狀態訊息切成英文，再切回繁中；沒有簡體中文文案。
- 照片可載入；按轉換時模型載入並輸出與原圖視覺不同的 PNG。
- 可切換三幅畫作與自選參考圖；風格強度改變輸出。
- 模型、相機、格式錯誤有明確提示；未完成轉換時不能下載。
- 下載結果為有效 PNG；使用者照片未送往網站後端。

## 後續

若要達到原附圖的真正 Q 版多人重繪，需另做模型與硬體可行性驗證。若要 QR 碼供旁人下載，需增加暫存服務或點對點傳輸機制，GitHub Pages 本身不提供每位使用者的結果儲存。
