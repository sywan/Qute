# Qute v0.2.2：拍照調整與自選參考圖品質

## 本版已實作

- 相機預覽可左右翻轉，調整亮度、對比與飽和度；提供「自然／明亮／鮮豔／柔和」四種預設與重設按鈕。預覽與拍下的 JPEG 套用相同設定。調整僅作用於本次拍攝，不改寫相機或系統設定。
- 自選參考圖的預設風格強度改為 60%，細節保留預設 35%，可由訪客自行調整。細節保留會把部分原照混入風格結果，以減少大片塗抹並保持臉部可辨識度。
- 移除二次風格遷移選項。它可能讓 Q 版參考圖造成更大塊的紋理，也會增加處理時間。

## Q 版效果的實際界線

目前的 Magenta.js 任意風格遷移模型可借用參考圖的色彩與紋理，不會可靠地改變人物頭身比例或重畫五官。因此，細節保留改善的是「塗抹與辨識度」，不是「真正 Q 版」。團體照中人物較小時，原本 640px 的模型輸入也可能讓臉部資訊不足。

## 建議的下一階段：真正 Q 版生成

需要另開生成式影像工作流：以原照作 image-to-image 輸入、以參考圖作風格條件，並評估姿勢／輪廓約束、多人臉部一致性與人數驗證。可先做少量團體照的品質試驗，再決定模型與服務形式。驗收標準應包含：人數一致、人物位置及主要服裝可辨、臉部清楚、Q 版比例明顯、沒有多生或消失的手臉。

GitHub Pages 仍可維持免登入的公開前端，但靜態頁面無法安全存放付費推論服務的金鑰。若採雲端生成，需要另外部署後端、設置匿名使用限額、處理費用與照片保存期限，並明確告知訪客照片會傳送到哪裡。若維持完全本機處理，需評估下載模型大小、WebGPU 支援、手機效能與等待時間；不能保證所有訪客裝置可用。實作前先用真實團體照測試模型品質，避免重複現有風格遷移的問題。
